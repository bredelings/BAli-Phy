# NAME

**draw-graph** - Write a multiconnected tree in Graphviz DOT format.

# SYNOPSIS

**draw-graph** _file_

# DESCRIPTION

Write a multiconnected tree in Graphviz DOT format. The required _file_ contains a
Newick tree and/or taxon partitions.

# INPUT OPTIONS:
**-h**, **--help**
: produce help message
