# NAME

**draw-graph** - Write a multiconnected tree in Graphviz DOT format.

# SYNOPSIS

**draw-graph** _file1_

# DESCRIPTION

Write a multiconnected tree in Graphviz DOT format.

# INPUT OPTIONS:
**-h**, **--help**
: produce help message

**--file** _arg_
: File containing a Newick tree and/or taxon partitions.
